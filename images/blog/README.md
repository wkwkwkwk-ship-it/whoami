# images/blog/

Folder ini untuk menyimpan gambar yang dipakai di artikel blog.

## Konvensi Penamaan
- Format: `post-{nomor}-{deskripsi-singkat}.{ext}`
- Contoh: `post-01-hero.jpg`, `post-01-diagram-sales-engineering.png`
- Gunakan format JPG untuk foto, PNG untuk diagram/grafik
- Ukuran disarankan: max 1200px lebar, compress sebelum upload

## Cara Pakai di Artikel
```html
<img src="images/blog/post-01-nama-file.jpg" alt="Deskripsi gambar" class="post-img" />
```
